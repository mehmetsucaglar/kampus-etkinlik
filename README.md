# kampus-etkinlik
Bu proje, üniversite kampüsündeki etkinlikleri listelemek ve yönetmek amacıyla hazırlanan "Kampüs Etkinlikleri" web uygulamasının iskelet (Sprint 1) aşamasıdır.

## Proje Hakkında
- Bu sprint kapsamında yalnızca **semantik HTML** kullanılmıştır.
- Herhangi bir harici/dahili CSS veya JavaScript kodu **içermez**.
- Tüm sayfalar ortak semantik iskelete (`header`, `nav`, `main`, `footer`) sahiptir.
- Form alanlarında görünür etiketler (`<label>`) ve zorunlu alan doğrulamaları (`required`) bulunmaktadır.
